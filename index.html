Tentang Pengaman Ini

SlashSMP Belajar adalah halaman statis (siap di-host di GitHub Pages), jadi token dan IP Owner tersimpan di penyimpanan browser perangkat ini — bukan di server. Artinya pengaman ini mengatur siapa yang bisa masuk dari perangkat ini, dan bukan pengganti keamanan server sungguhan.
