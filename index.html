Catur

Catur lengkap dengan aturan resmi: langkah legal, skak & skakmat, rokade, en passant, dan promosi pion. Ada rating ELO yang hanya berubah di mode Online melawan pemain asli — melawan bot (coach lokal maupun bot pengganti) ELO kamu tidak berubah, menang atau kalah — plus penilaian tiap langkah (Brilliant, Terbaik, Sangat Baik, Bagus, Baik, Salah, Blunder), tombol Nyerah dan Tawar Remis, lawan bot dengan ratingnya sendiri, mode 2 pemain offline di satu HP, dan mode Online asli: tersambung ke server catur — tekan Main Online dan kamu langsung masuk antrean matchmaking acak (tanpa memilih lawan, tanpa tombol tantang), pemain asli diprioritaskan dan bot pengganti dari server mengisi bila antrean pemain asli kosong, lengkap dengan bendera negara lawan di bar pemain dan chat cepat; bila server tidak terjangkau dari browser, mode cadangan (simulasi) berjalan otomatis dan statusnya ditampilkan apa adanya. Jam catur dipilih dulu dan berlaku di semua mode; khusus mode Online jam wajib dipakai. Di atas dan bawah papan ada bar pemain ala aplikasi catur: lencana title + nama + ELO, baris bidak yang ditangkap, dan jam di sisi kanan. Di mode 2 pemain, nama Putih & Hitam bisa ditulis sendiri dan ada pilihan rotasi papan. Ketuk bidakmu untuk melihat langkah yang boleh, lalu ketuk petak tujuan. Ada juga premove: selagi giliran lawan, ketuk bidakmu lalu petak tujuan untuk menyimpan langkah (tampil biru di papan) — otomatis jalan begitu giliranmu tiba, bisa dibatalkan dengan mengetuk petak premove-nya, dan bisa dimatikan di Pengaturan. Ada juga Rekam Video Partai: rekam jalannya partai jadi video langsung dari papan — lengkap dengan bar pemain, jam, dan langkah terakhir — lalu unduh videonya untuk disimpan atau dibagikan. Dan ada Warna Papan & Latar: 12 tema warna papan dan 12 latar belakang area main yang bisa diganti kapan saja — pilihanmu tersimpan di perangkat ini dan ikut dipakai di video rekaman partai.

Jam berjalan untuk kedua pemain di semua mode (bot, 2 pemain, dan online). Khusus mode Online, jam wajib dipilih — kalau "Tanpa jam" yang dipilih, otomatis diatur 10 menit.
Geser untuk mengatur kekuatan bot: 100 paling mudah, 2500 paling kuat. ELO tiap bot HIDUP seperti pemain — menang naik, kalah turun — dan tersimpan untuk bot itu; angka di sini adalah rating bot terpilih saat ini (saat main bisa bergeser acak ±10). Lawan selalu disetarakan di sekitar ELO kamu (maksimal beda ±150) supaya partainya seimbang dan seru. Melawan bot tidak mengubah ELO kamu — ELO kamu hanya berubah di mode Online melawan pemain asli.
Nama dan rotasi berlaku saat menekan Partai Baru. Nama bot/coach di mode Lawan Komputer tidak bisa diganti — tetap nama coach-nya.
Di mode Online, warna selalu diacak adil oleh server untuk kedua pemain — tidak ada memilih sisi, sama seperti main online beneran.
Server: belum terhubung
Lobi Online ● 0 pemain online
Tekan Main Online untuk langsung masuk antrean matchmaking server — tanpa memilih lawan dan tanpa tombol tantang: server mencarikan lawan acak dan pemain asli diprioritaskan, jadi kalau temanmu menekan Main Online di waktu yang berdekatan, besar kemungkinan kalian dipertemukan. Kalau antrean pemain asli sedang kosong, bot pengganti dari server yang mengisi supaya kamu tetap bisa main — statusnya tampil selama pencarian ("Mencari pemain asli…" lalu bot pengganti disiapkan). Nama, negara, bendera, title, dan ELO lawan ditentukan server saat matchmaking, jadi kekuatannya tidak bisa ditebak sebelum bermain. ELO hasil partai online dihitung server. Untuk lawan bot lokal dan lawan mode cadangan, ELO lawan selalu disetarakan di sekitar ELO kamu (maksimal beda ±150) supaya partainya seimbang. Pilihan region hanya berlaku pada mode cadangan. Melawan bot pengganti (dari server maupun simulasi), ELO kamu tidak berubah — ELO hanya dipertaruhkan saat melawan pemain asli. Catatan koneksi: server juga bisa dihubungi lewat Cloudflare Tunnel gratis beralamat wss://…trycloudflare.com (terenkripsi, tidak diblokir browser dari halaman https ini) — alamat tunnelnya ditempel Owner di Panel Owner dan berubah setiap server di-restart. Bila alamat tunnel belum diatur, website mencoba alamat ws:// langsung yang biasanya diblokir browser dari halaman https; bila server tetap tidak terjangkau, mode ini otomatis memakai mode cadangan (simulasi) dengan bot lokal dan statusnya ditampilkan apa adanya.

Dompet Pak Darma

Sore itu, Raka pulang sekolah dengan berjalan kaki seperti biasa. Langit mulai jingga, dan angin bertiup pelan melewati gang kecil di dekat rumahnya. Saat menyeberangi jembatan kecil di ujung gang, mata Raka menangkap sesuatu yang tergeletak di pinggir jalan: sebuah dompet cokelat yang tampak tebal.

Raka memungut dompet itu dan membukanya dengan hati berdebar. Di dalamnya ada uang seratus lima puluh ribu rupiah dan sebuah KTP atas nama Pak Darma, tetangga yang tinggal di ujung gang. Jantung Raka berdetak lebih kencang. Uang sebanyak itu cukup untuk membeli mobil-mobilan remote yang sudah lama ia lihat di etalase toko dan sangat ia inginkan.

“Tidak ada yang melihat,” bisik Raka dalam hati. “Kalau aku ambil, tidak ada yang tahu.”

Tetapi langkahnya terhenti. Ia teringat pesan Ibu Guru Sari di kelas minggu lalu: “Anak-anak, barang yang bukan milik kita, seberapa pun kita menginginkannya, tetap bukan hak kita. Kejujuran itu seperti cahaya — kecil pun ia tetap menerangi hati.”

Raka menarik napas panjang, lalu berbalik arah. Ia berjalan ke rumah Pak Darma dan mengetuk pintunya. Pak Darma membuka pintu dengan wajah cemas — sedari tadi ia mencari dompetnya ke mana-mana. Ternyata, uang di dalam dompet itu hendak ia pakai untuk membeli obat untuk istrinya yang sedang sakit di rumah.

“Terima kasih, Nak Raka. Kamu anak yang jujur,” kata Pak Darma sambil tersenyum haru. “Uang ini sangat berarti untuk kami.”

Raka pulang dengan langkah ringan. Mobil-mobilan remote itu memang belum bisa ia beli, tetapi hatinya terasa tenang dan hangat — jauh lebih berharga daripada mainan apa pun. Ia berjanji pada dirinya sendiri: apa pun yang terjadi, ia akan selalu memilih jujur.

IP Owner Otomatis

Dengan fitur ini, SlashSMP Belajar mengenali kamu dari IP perangkat ini: setiap kali halaman dibuka dari IP yang sama, kamu langsung masuk sebagai Owner tanpa token. Demi keamanan, angka IP tidak pernah ditampilkan di layar — yang tampil hanya statusnya saja. Bila IP berubah karena berganti Wi-Fi atau paket data, masuklah memakai token akses yang sudah kamu buat, lalu daftarkan IP yang baru dengan tombol di bawah.

Tunnel Server Catur — Cloudflare (Gratis)

Website ini adalah halaman https, sedangkan server catur di panel hanya punya alamat ws:// polos — browser memblokir koneksi itu, jadi mode Online selalu jatuh ke mode cadangan. Server catur v1.3.0 menjalankan Cloudflare Tunnel gratis dan mendapat alamat terenkripsi wss://…trycloudflare.com. Alamat tunnel tampil di console server saat server start, dan juga bisa dilihat dengan membuka alamat /health server di browser. Salin alamatnya, lalu tempel di sini — mode Online dari perangkat ini lalu tersambung lewat tunnel. Perhatian: alamat tunnel berubah setiap server di-restart, jadi tempel ulang alamat barunya di sini setiap habis restart server. Alamat ini tersimpan di perangkat ini.

Status Alamat TunnelBelum diatur

Title OWNER Eksklusif

Title paling istimewa di SlashSMP Belajar: lencana emas OWNER dengan mahkota. Title ini tidak bisa didapat dari ELO dan hanya bisa dipakai oleh kamu sebagai Owner — pengunjung, bot, dan coach tidak akan pernah memilikinya. Selama kamu masuk sebagai Owner, title ini tampil di Profil, di bar pemain saat bermain catur, dan di ringkasan partai; begitu kamu log out, title ini hilang dan profil kembali ke title ELO biasa.
